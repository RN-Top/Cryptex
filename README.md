# 🗝️ Drew's Cryptex — 6-Ring Cylinder Cipher & Divination App

A web application that transforms the physical 6-ring cylinder cipher device into an interactive digital divination wheel and word-alignment game. Built with [Streamlit](https://streamlit.io/) and ready for one-click deployment on **Streamlit Community Cloud** and **GitHub**.

---

## 🌟 What is this Device?

Drew built the original physical mechanical 6-ring brass cipher device. This web application transforms Drew's physical hardware invention into an interactive digital software app (historically rooted in the 1795 Jefferson wheel cipher and the Da Vinci Cryptex), featuring custom handwritten letter strips taped across each brass ring.
